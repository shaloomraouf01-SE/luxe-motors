# LUXE MOTORS — premium automotive portfolio concept

Static, multi-page website using HTML, CSS and vanilla JavaScript. Open `index.html` in a browser; no installation needed.

Pages: Home, Collection, Vehicle Details, Our Story, Contact, Compare.

Features: responsive mobile navigation, search/filter/sort, persistent favorites and compare shortlist via localStorage, vehicle details, demo enquiry form.

**Demo only:** all vehicle entries, figures, brand and dealership are fictional sample content. No backend, live vehicle stock, appointment booking or message delivery. Remote images from Unsplash and Google Fonts require an internet connection. Images depict illustrative models and may not match the listing names exactly.
